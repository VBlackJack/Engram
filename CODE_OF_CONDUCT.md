# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: participate with the assumption that the other person is acting in good faith, keep
disagreement about the work rather than about the person, and accept that a maintainer may say no
to a contribution without that being a judgement of you.

Report unacceptable behaviour privately through
[GitHub security advisories](https://github.com/VBlackJack/Engram/security/advisories/new), which
is the only private channel this repository has. Reports are handled by the maintainer, who will
respond as promptly as a project of this size allows.
